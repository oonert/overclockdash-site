# overclockdash.com

The OVERCLOCK website. The clock on it is the real firmware (demo build) running in the browser, built from the firmware repo's `overclock-dash/tools/web` folder. Do not edit `overclock.js`, `dist/`, `frame/` or `lib/` here; they are copied from that folder when the browser clock is rebuilt.

Hosted on GitHub Pages at overclockdash.com.
